# Workshop Presença — Modelagem e consultas SQL

Repositório de estudo dedicado à construção de um banco de dados relacional e à prática de consultas SQL em um cenário de controle de participantes e presença em workshops.

## Objetivo

Praticar a criação de tabelas, inserção de dados de exemplo e elaboração de consultas para recuperar informações relacionadas. O foco do repositório está na camada de dados e no raciocínio com SQL.

## Organização dos scripts

```text
workshop-presenca/
└── sql/
    ├── 1.banco e tabelas.sql
    ├── 2.seeds.sql
    └── 3.queries.sql
```

- **1.banco e tabelas.sql:** estrutura inicial do banco e definição das tabelas.
- **2.seeds.sql:** dados de exemplo para popular as tabelas.
- **3.queries.sql:** consultas para explorar os dados cadastrados.

## Tecnologias e conceitos

- SQL
- Banco de dados relacional
- Criação de tabelas
- Inserção de registros
- Consultas e relacionamentos

## Como utilizar

1. Abra os arquivos SQL em um cliente de banco de dados compatível com MySQL.
2. Execute primeiro o script de criação do banco e das tabelas.
3. Execute o script de seeds para inserir dados de teste.
4. Execute as consultas do terceiro arquivo.

É importante respeitar a ordem dos scripts para que as tabelas existam antes da inserção e consulta dos registros.

## Aprendizados

O exercício reforça modelagem relacional, organização de scripts SQL e consulta de dados. É uma prática importante para projetos back-end que precisam persistir e relacionar informações.
